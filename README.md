VOIDSTORM is a neon arena space shooter: hold the line against waves of raiders, chain kills for combo score, grab shield / spread / rapid-fire pickups, drop a nova bomb when the sky fills up — and face a Dreadnought every 5th wave. One ship, three hull, no mercy.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network requests, everything (art, sound, logic) is local. WASD / arrows to fly, mouse to aim, hold click or Space to fire, Q for a nova bomb, P to pause, M to mute.
